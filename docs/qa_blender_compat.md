# Blender 互換QAチェックリスト（3.6 LTS / 4.5 LTS）

## 事前準備
- Blender 3.6 LTS と 4.5 LTS の両方でアドオンを有効化する。
- テスト用 PSD を 1 つ以上用意する（複数レイヤー + グループを含む）。

## チェック項目
1. アドオン有効化
   - エラーなく有効化できる。
2. PSD インポート
   - `PSDTool > import PSD` から PSD を読み込める。
   - Plane が作成され、画像が表示される。
3. レイヤーUI
   - `PSD layers` パネルが表示される。
   - オブジェクト未選択時に UI が落ちない（案内表示のみ）。
4. 表示切り替え
   - レイヤーの表示/非表示ボタンで見た目が更新される。
5. マテリアル生成
   - Principled / Emission の両方でマテリアル作成がエラーなく完了する。
6. コンソール
   - 操作中に例外 traceback が発生しない。

## 判定
- 上記を 3.6 LTS / 4.5 LTS で満たしたら互換OK。
